# KGEssentials-endstone

KGEssentials adalah plugin **Endstone** yang menyediakan berbagai utilitas esensial untuk server Minecraft Bedrock, dengan fitur yang dirancang agar sederhana dan mudah dikembangkan.

## Informasi

- **Endstone:** v0.11.10
- **Versi Plugin:** v0.1.0
- **Bahasa:** Python
- **Lisensi:** MIT

## Fitur Saat Ini

- Perintah gamemode: `/gmc`, `/gms`, `/gma`, dan `/gmsp`
- Perintah `/spawn` untuk teleport ke spawn server
- Perintah `/setspawn` untuk mengatur lokasi spawn KGEssentials
- Perintah `/rtp` untuk teleport ke lokasi acak yang aman
- Sistem konfigurasi dan pesan berbasis YAML
- Sistem permission untuk setiap fitur
